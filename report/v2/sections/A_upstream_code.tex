\section{Upstream Code and Corrections}\label{app:upstream}

The localization filters, resampling schemes and resampling rules come from the particle filter tutorial of
Elfring et al.\ \cite{elfring2021particle} (commit \texttt{e6014b7}, MIT); FastSLAM 1.0 and 2.0 from
PythonRobotics \cite{sakai2018pythonrobotics} (commit \texttt{1fe4fb9}, MIT). The upstream code is downloaded at
these commits and never modified: the schemes and rules are called unchanged, while the models, proposals and
FastSLAM updates are copied, vectorized over particles, and moved to log weights. Every correction can be
switched off, and with them off the copies match the upstream functions on the same inputs and random numbers;
those comparisons are part of the test suite.

Three corrections change a result reported here. The localization likelihood omits the Gaussian's normalizing
constant, which cancels once
the weights are normalized but is the term that penalizes a wider assumed noise; without it the marginal
likelihood \eqref{eq:evidence} grows without bound and the learning sweeps have no maximum.
FastSLAM resampling copies the list of particles but not the particles themselves, so resampled particles share
their state and their landmark arrays, which would have hidden the difference between the schemes. And the
likelihood compares bearings without wrapping the difference, so a small error across $\pm\pi$ looks like almost
$2\pi$. Nine further errors, none of which changes a conclusion, are corrected in the code and listed there.
